# Engineering Foundations Book

A dependency-free static revision book. Open `index.html` in a browser.

## Add a topic

Edit `chapters.js` and add another topic object inside a chapter's `topics` array. The table of contents, search, counters, and previous/next navigation are generated automatically.

To add a new chapter, copy the existing chapter object, give it a unique `id` and `number`, and replace its topics.

No build step or package installation is required.
